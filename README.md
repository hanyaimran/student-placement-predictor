🎓 Student Placement Prediction

A machine learning web app that predicts student placement outcomes using CGPA and IQ.

🤖 Machine Learning

* Algorithm: Logistic Regression
* Task: Binary Classification
* Features: CGPA + IQ
* Preprocessing: StandardScaler
* Output: Placement prediction + probability

⚙️ Pipeline

Dataset → Train/Test Split → Scaling → Logistic Regression → Prediction

🛠️ Tech Stack

Python • Pandas • NumPy • Scikit-learn • Streamlit
